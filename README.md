# Machine Learning Homework

## HW1
1. 透過散佈圖(Scatter plot)視覺化分析鳶尾花資料集(Iris data set)特徵的鑑別度。
2. 利用程式自主實現K-NN分類器，並利用其進行Iris data set之訓練及測試，求出分類率。

## HW2
1. 透過自己實現之Linear Discriminant Analysis (LDA)演算法對鳶尾花資料(Iris data set)進行分類。
2. 利用ROC曲線和AUC觀察調整懲罰權重對模型表現所造成的影響。
3. 進一步測試多類別分類策略（e.g. One against one strategy）。

## HW3
1. 利用鳶尾花資料(Iris data set)來訓練Support Vector Machine (SVM)。
2. 分別比較線性與非線性SVM所訓練的超平面(hyperplane)有何差異。

## HW4
1. 利用鳶尾花資料(Iris data set)來訓練Support Vector Machine (SVM)，採用one-against-one strategy來處理三類別分類問題。
2. 以grid search來最佳化SVM之參數C與sigma。
3. 其過程再以two-fold cross validation使所得到的最佳參數組具有較佳的泛化性。

## HW5
1. 實做兩種特徵篩選方法(Sequential Forward Selection 和 Fisher’s Criterion)。
2. 比較 Filter-based 和 Wrapper-based 特徵篩選法的異同。
3. 利用乳癌資料集，搭配 LDA 分類器和2-Fold CV 完成分類任務，並使用平衡分類率以評估分類器效能。
4. 乳癌資料集, Breast Cancer dataset：https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
